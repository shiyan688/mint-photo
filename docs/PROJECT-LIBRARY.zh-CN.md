# 本地命名作品与独立副本（v25 源码检查点）

## 使用

点击顶部「作品库」。它保存的是继续编辑的本地工程，不是只保存一张导出成片。

- **保存当前**：第一次新建；已打开命名作品时覆盖它的对应版本。输入作品名称，最多 80 个 Unicode 字符。
- **另存独立副本**：创建独立 ID 和参数快照。以后修改副本不会修改原作品。
- **打开**：先检查文件、参数和实际重放；成功前不替换当前照片。当前未保存的已应用编辑会先进入可恢复回收区，并明确确认。未应用预览另行提示，不会偷偷写入历史。
- **新照片**：打开本机文件选择器；选完后执行相同的保护流程。取消选择或确认时保留当前作品。
- **复制 / 回收区 / 恢复**：列表可复制已有快照。移入回收区需要确认，恢复仍保留原始文件与历史；当前已打开画面不会被删除。本版没有永久删除和自动清空。

保存包括当前主照片的原始 Blob、来源尺寸、已应用步骤、重做历史，以及原本已经嵌入工程的贴图和拼图工作副本。第二张贴图/拼图仍受各自工作副本分辨率限制，作品库不会恢复早已未保留的原文件细节。所有处理都在本机，不新增上传或联网权限。

导出 PNG/JPEG 只保存成片，**不等于保存可编辑工程**。清除应用数据、浏览器站点数据、卸载或系统回收站点存储仍可能使这些本地工程丢失。没有云同步。v27 已新增独立的手动工程备份/恢复，详见 PROJECT-BACKUP.zh-CN.md；只保存在本机作品库不能代替外部备份。自动草稿恢复后不会猜测绑定到某个命名作品，防止覆盖不确定版本。

## 容量及失败行为

- 命名作品和回收区合计最多 **24 份**，每份逻辑数据最多 **64 MiB**，合计最多 **192 MiB**。
- 自动草稿单独最多 64 MiB；空间读数只统计命名作品和回收区，不是设备剩余空间。
- 原图压缩字节和配方/内嵌资产都计入；数据库索引、事务临时副本及浏览器开销未计入。实际系统配额可能更早不足。
- 独立复制按完整数据大小计数，不承诺浏览器物理去重。回收区仍占名额和空间，不能靠移入回收区腾出容量。
- 达到限额时仍可在预算内覆盖当前已命名作品；若新建或切换必须创建恢复副本而没有空间，会明确拒绝，不牺牲未保存历史。没有隐藏的永久清理按钮。
- 元数据与工程快照在同一事务提交，事务完成后才报告成功。损坏、配额失败、版本冲突或升级阻塞会保留当前编辑，不报告“已保存”。多个窗口覆盖同一命名作品使用版本检查；自动草稿仍是旧的最后写入者语义，**不要同时在多个窗口编辑同一个自动草稿**。
- 存储不可用时无法安全完成打开/换图流程，会停止切换。旧 v1 数据库保留原草稿；旧工程按原质量来源恢复，不把旧工作副本冒充完整原图。

## 已测与未测

已执行生产 JavaScript 的结构/限额/事务故障注入、UI 状态、确认/Back、迟到回调、保存竞态、旧格式恢复。实际生产编辑器搭配已安装 NativeCanvas，已解码原始 PNG、重放滤镜/贴图/构图并重新导出 PNG：保存前后 RGBA 逐字节相同，原始 Blob、撤销/重做与资产保持。

**IndexedDB 和 DOM 的测试后端是受控模拟，不是真实浏览器事务或 Android 持久化验证。** 本轮没有获得可用的浏览器运行结果，已停止失败探测，未更改浏览器安全设置。没有实测 WebView 冷启动、进程被杀、真实设备磁盘不足、系统清理存储或触控布局。未签名构建成功不等于可安装版本或手机验收。旧签名 APK 不变。
