# 与醒图的功能差距台账

核对日期：2026-10-24。薄荷发布基线：0.2.0-preview；开发分支：0.3.2-dev。结论：未达到醒图整体水平。

参考公开 App Store 页面显示版本15.7.0，且包含历史更新。它是iOS资料，不能据此声称覆盖当前Android版全部功能；尚未进行醒图Android真机逐菜单盘点。下表是已核对源码的需求台账，含待竞品实机确认项，不是完整竞品功能清单。

## 验收方法

每项分别记录：实际入口、核心输出、取消与回放、跨尺寸/透明度、真实照片局部对照、资源消耗与真机结果。合成指标只能证明限定性质，不等于自然照片审美质量；没有醒图同图输出前不公布接近程度或百分比。

## 实施顺序

1. 本地自动光线与批量调色，保留原图和独立失败处理；用真实像素测试。
2. 独立降噪/高分辨率预览、内容修复与人像算法版本化，旧工程重放不可偷偷变样。
3. 用户已选择本地基础＋可选联网AI。接通受控服务后再逐项完成消除/扩图/修复；未连接、未出图与未验证一律仍记缺失。
4. Android逐菜单盘点、同图比较、真机内存/触摸/导出验收持续补齐。

## 当前实现检查点

安卓原生HTTPS传输、自填API、消除涂抹蒙版和扩图透明画布链路已实现；已在API35模拟器通过原生HTTPS模拟服务、触屏、系统保存/重新打开与独立PNG核对；没有真实供应商出图或实体手机验收。AI消除/扩图仍是未完成验收，超清继续缺失。安卓批量保存未接入。纹理修肤与亮度引导边缘贴合为明确版本的试验选项，旧工程保留原算法；真实照片对照与限制见 [最新验收记录](AI-ANDROID-QUALITY.md)。

自动光线两份人工压暗样例的RGB误差下降，但目检仍偏暗；属于有限、保守的曝光改善，未做醒图同图或肤质审美盲评。详见 [本轮验证](FUNCTIONAL-PROGRESS.md)。

性能、工具入口简化和多照片缺陷记录见 [本轮验证](PERFORMANCE-UI-QUALITY.md)。
