# 四角透视校正

这是常规离线几何变换，不是图像生成、超分辨率或自动镜头标定。不依赖网络、额外模型或新权限。

## 使用

1. 在当前作品打开“透视”。拖动左上 TL、右上 TR、右下 BR、左下 BL 四个角，或输入相对当前处理阶段的百分比。角点不会自动交换身份。
2. 必须保持凸四边形及顺时针顺序。交叉、凹形、过小边或不稳定投影会被拒绝，不会用猜测的排列修改照片。
3. 明确设置输出宽、高，再点“校正预览”。预览与源坐标选角是两个视图；校正预览里不能误拖未校正坐标。可返回选角继续改。
4. 四边形以外内容会裁去。输出比例由用户决定，可能改变物体比例，不推断相机位置或物体真实尺寸。拉伸不增加细节。
5. 主“应用”只提交一个可撤销步骤；重置回到完整原画面。取消、第二根手指、pointercancel、切到后台会取消本次未提交角点拖动，保留先前历史。

## 原图、坐标与导出

- 原始文件 Blob 不被重写。透视是已有操作之后的顺序步骤，先前克隆、画笔、贴图或遮盖按原有阶段重放，不重新解释旧坐标。
- 配方保存当前阶段像素边缘的归一化四角，输出宽高保存为当前阶段完整输入宽高的比例。坐标是边缘，不是像素中心；不保存900长边预览的坐标或尺寸。
- 原尺寸 / 工作尺寸分别重算与预算。工作尺寸会按同一比例得到较小输出，不冒充原尺寸。输出规划显示明确尺寸；预览缩小不能绕过完整导出预算。
- 应用后照片 revision 改变，即使输出尺寸没变，也会使旧人脸缓存失效；迟到识别回调不写回新画面。后续人像处理需从当前阶段重新识别。
- PNG 保留透明度；JPEG 按既有导出流程白底合成。辅助网格和标签不进入导出。主中性操作与精确整数裁切逐字节复制，包括透明像素中的隐藏 RGB。

## 资源与采样

手机适配限制输入和声明输出各不超过 800 万像素、最长边4096。临时 RGBA / ImageData / Canvas 及预滤波层保守总预算128MiB，全部透视步骤累计计算预算1.28亿采样单位。超预算在读回输入像素或新建输出前拒绝，不偷偷改变声明尺寸。

非整数重采样在线性光、预乘 alpha 下计算，避免透明隐藏颜色污染边缘。缩小时采用有预算的多级预滤波与有界方向采样；具体冻结版本、预算公式及极端限制见 PERSPECTIVE-CORE-CONTRACT.md。它不保证极端斜切、压缩或低分辨率源始终清晰，也不恢复拍摄时已丢失的细节。
