# 手动精修：云端开发检查点

2026-10-22，候选版本 1.2.0。以下功能已接入 Android 源码与离线预览；当前构建未签名，不是可安装更新。未做本轮 Android 真机或真实 WebView 操作验收。

## 已实现的工具

- **选区**：涂选、套索、增选/减选、全选、反选、清空、取消范围限制、羽化、绿色覆盖显示、撤销选区一笔。空选区保护全部像素；取消限制才是不限制范围。
- **推 / 恢复液化**：使用共同位移场，恢复是向本轮输入恢复，不是再次模糊。限制过大工作量和极端变形。透明输入暂时拒绝液化，防止固定 alpha 裁掉移动后的轮廓；先在不透明原图上液化，再重新抠图。
- **纹理修复**：从真实供体取样，按周围环带匹配颜色，再以软边混合。保留借来的高频纹理，不是只填周围平均色，也不是生成式补图。
- **仿制图章**：必须明确点击取样点，真实复制纹理。每笔起点对齐供体，本笔的偏移保持固定；下一笔重新从该取样点开始。允许重叠供体，但读的是笔划开始前的不可变图像，不会发生边画边反馈。
- **大小 / 硬度 / 强度**：均影响真实笔划；强度为零、空选区或相同供体导致无像素变化时，不记录假成功。
- **历史**：撤销一笔、清空本次、取消本轮、应用后全局撤销/重做。保存原始照片 Blob，记录命令，不把预览覆盖为原图。

## 使用顺序

1. 打开照片，进入「精修」。需要限制范围时，先涂选或套索，可羽化。
2. 选择「推」轻推；需要时使用「恢复液化」。
3. 选择「纹理修复」或「仿制图章」，点「选择取样点」，再点干净且颜色相近的位置。这个取样点击不会编辑照片。
4. 用短笔轻涂目标位置，松手生成预览。每笔保存当时的选区；之后修改当前选区不会重新解释旧笔划。
5. 查看、撤销或应用。修复之后若想再推，请先应用本轮，再进入下一轮。

自动邻近取样仅在 Android 离线人脸定位可用时提供，适合无遮挡皮肤的小区域。眼、眉、唇和脸部边界由关键点几何保护；这不是皮肤/发丝分割。发丝、胡须、手或其他遮挡可能位于脸部几何范围内，应手动选择供体。液化后必须先应用，再重新识别人脸，不能继续使用旧关键点。

## 回放和边界

- 坐标保存在每一步输入图像的归一化空间；半径与羽化按短边比例保存。完整导出重新栅格化选区，不放大预览蒙版。
- 同批顺序固定为液化 → 修复。验证器和渲染器都会拒绝同批液化与自动修复的旧关键点组合，不只在按钮层禁用。
- Android 是按应用顺序重放的栅格操作链。新背景/自动塑形会对当前已提交图像重新定位；没有桌面版全局图层重排语义。
- 修复仅限短笔小区域：最多 2048 个保存点，路径不超过 12 个半径，笔划有效覆盖不超过照片 4.5%（小图有固定余量）。手机一轮最多 20 笔液化与 20 笔修复。大块移除会明确拒绝。
- 纯核心上限约 1600 万像素；**手机导出仍按更严格的 800 万像素 / 4096 边长检查**。超过限制可选择最长边 2560 的工作尺寸；不能声称已验证 39MP 原尺寸修复。
- 旧项目的旧 heal/warp 命令仍可读取重放，但新工具入口不会悄悄降级为旧版平面填色。缺少核心时明确失败。
- Android 项目格式与桌面项目格式不同，共享像素核心不等于项目可互换。

## 已测与未测

已运行：共享选区/液化 20 个纯回归；修复 20 个纯回归；新手动 UI 12 个 DOM/像素回归；现有生产编辑器 47 个状态检查使用真实新手动模块，包括应用、撤销、重做、取消、模式切换、模型缓存失效。整个纯测试集合共 321 个检查，另有 26 个 Java 导出验证检查。

独立像素 QA 使用公开 NASA 成年人肖像的 897×1000 派生图，以及明确标注的合成图案。5 个合成黑点的目标像素 MAE 降到原误差的 2.6%–4.4%；柔和合成红色也明显减弱，但不能把换供体后的原图像素误差解释为去红率。供体仍可能带来少量亮度/颜色偏移。原图中的一个测试者选定自然色差点，修复和仿制均有真实输出，笔刷外像素没有变化；这不是现实痘痘的真值验证。

未验收：本轮手机运行/触控手感、真实浏览器布局、真实大图内存峰值、多种实际肤况与复杂遮挡、专业内容移除、学习型皮肤修复、SOTA 或商业修图质量。同步像素执行可能在低性能手机上短暂停顿；取消手势/本轮和核心中断回调已测，不承诺同步计算中界面可即时抢占。
