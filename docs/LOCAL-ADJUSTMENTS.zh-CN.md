# 局部调色：云端源码检查点

这轮增加的是可实际改变像素的手动局部调色，不是自动语义选区、AI 美颜模型或 SOTA 声明。没有新的签名 APK；未签名构建不能安装。

## 怎么用

1. 导入照片，打开「局部调色」。选择「径向」「渐变」或「手绘选区」新增一层。每层参数从 0 开始，不自动美白或改脸。
2. 径向可以在图上拖动位置，独立调横纵半径和羽化。渐变可拖出两端，也可用数值滑杆精调和反向。
3. 手绘支持涂选、套索、加选、减选、全选、清空、反选和羽化。松手后才保存一笔；取消、失焦或换照片不提交半笔。
4. 调曝光、对比、饱和、色温，或图层不透明度。支持图层命名、切换、显隐、删除和本轮局部撤销。显示蒙版只用于操作提示，不烘焙进照片。
5. 一轮最多 8 层，点击「应用」作为一个历史步骤保存。整组可用主撤销/重做恢复，原文件不覆盖。

当前不是完整的 PSD 式自由图层编辑器。应用后重新进入会建立新的一轮，不能直接点开更早的组重编每层；可撤销那一组后重新编辑。

## 重放与范围

- 复用桌面现有的局部调色像素核心，没有重新发明另一套曝光参数。所有调色值为 -100 至 100，0 是精确不变。
- 每个操作保存自己的蒙版和修订号。坐标相对于该步骤输入的图像，所以先裁剪后局部调色与先局部调色后裁剪有不同含义，按原顺序重放。
- 图形蒙版在每次实际渲染尺寸下重新计算，不将低分辨率预览蒙版拉伸后冒充原尺寸。空选区保护全部像素；权重为 0 的域外字节、alpha 和透明像素隐藏 RGB 保持不变。
- 径向、线性渐变和手绘并不是自动人像/肤色/头发/亮度区间识别。本轮没有增加颜色范围或亮度范围蒙版。
- 当前原尺寸导出的应用上限仍是 800 万像素、最长边 4096；超过时保留原文件，并明确要求工作尺寸，不静默冒充满幅导出。
- 每轮最多 128 条选区命令、所有层合计 4096 个点；单次手势最多 512 点。复杂度超限会拒绝本次改动，不把错误蒙版当成全图。
- 取消检查在图层边界，而不是同步像素循环的每个时刻。实际手机速度、峰值内存和系统进程被杀后的恢复还需设备验证。
