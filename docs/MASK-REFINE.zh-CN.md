# v28 连续蒙版修边：使用和验证边界

## 能做什么

「背景」现在进入新的精细修边界面。可以先点「自动抠人像」载入已有离线模型的连续置信度，也可用「手动勾画」从空蒙版开始，再用「保留 / 擦除」。默认绿色检查层只帮助检查保留程度，不会进入作品或导出。

- 笔刷半径为当前步骤输入短边的 0.05%–25%，不是屏幕显示像素；硬度控制内侧实心区，强度控制每笔的混合量。0 强度不产生编辑。
- 撤销/重做笔划；「查看本步前」暂停绘制；「还原初始蒙版」需要确认。放大和平移继续沿用当前画布到配方坐标映射。第二触点或取消事件会撤回整个未完成笔划。
- 收扩边为短边 −2%–2%，采用连续置信度的收缩/扩张，不二值化；羽化为 0%–2%。处理顺序固定为：双线性基础置信度 → 有序笔划 → 收扩边 → 羽化。
- 同一笔沿完整折线计算覆盖，不随触摸事件密度多涂几层。同一路径稀疏/密集采样得到相同结果；不同笔有意按顺序累积。自动载入失败、超时或取消不会声称识别成功。

## 原图与历史

新操作为 `background-refine`；旧 `background` 配方保持原来的像素含义，不自动迁移。每笔保存规范化坐标和独立参数，并在该步骤实际输入分辨率重新计算。它不是把 长边 256 的小蒙版涂完再放大。裁剪、转向、翻转等先前步骤决定当前坐标；后续步骤不回写这些笔划。

新流程保存原文件、有序历史、重做与置信度基底，可经作品库和 `.mintproject` 备份恢复。备份包含照片与这些空间坐标，未加密。新界面校验当前照片/修订归属，迟到的识别结果不能套到另一份草稿。已保存操作重放不再次调用模型。

## 像素、资源与质量限制

新纯色合成使用连续 alpha 和线性光混合，透明导出乘以源 alpha，不凭空使原透明像素不透明。Canvas 对完全透明像素的隐藏 RGB 可能规范化；不承诺跨实现隐藏颜色逐字节相同。旧背景流程不改用新算法。

- 当前移动适配器上限 8,000,000 像素、边长 4096；同时检查核心工作量、累计重放工作量及额外缓冲计划。导出末尾缩小不能绕过较大中间输入的限制。
- 最多 128 笔、全配方 4096 点，单笔 2048 点。基础置信度最多 262,144 像素、边长 1024；实际原有模型输入长边仍为 256。
- 额外缓冲计划上限 256 MiB，不代表 Android 进程峰值内存或低端手机保证。同步计算的合作式取消不是主线程随时可中断的性能证明。
- **细笔划在原尺寸重放，不等于恢复模型从未看到的发丝细节。** 仍无新的发丝级 matting、前景去污染或颜色反卷积；复杂头发、透明物体、灰边需要人工检查。不是 SOTA。

## 实际验证

26 项纯核心、10 项新 UI 状态检查，另有 26 项独立回归。独立几何覆盖算法核对 29,041 像素；96 组边界组合包含极小笔刷、收扩边、羽化、窄长图及透明像素。完整编辑器的真实 PNG 验证包含 1800×1200 原尺寸导出、900×600 工作预览、取消/撤销、前后几何、旧背景兼容、绿色检查层不入图，以及新增蒙版工程备份恢复。

公开 NASA 成人肖像的 1000×1250 派生图使用已有官方 MediaPipe 模型在云端 CPU 推理，实际输入及输出基础蒙版 205×256。对照图明确展示两笔人为选定的右肩背景擦除；相对初始换背景结果，选定脸部区域改动为 0 像素。这不是 Android 推理一致性、真实多人现场、发丝质量或完整美颜验收。仍有未修完的灰边，不能从这一个局部推断全部照片质量。

- 小对照：`quality/mask-refine-evidence/comparison-zh.png`
- 模型与来源哈希：同目录 `public-host-model-mask.json`；照片出处继承 `quality/sharpness-evidence` 的公开 NASA 夹具说明。
- 真实手动配方：`public-refinement-recipe.json`；生成器：`tools/infer-mask-refine-fixture.py`、`tools/render-mask-refine-evidence.cjs`。
- 完整 PNG 在独立「安卓背景修边-v28-质量证据.zip」中；源码保留测试、配方、小图与报告，可重新生成。

## 仍然阻塞的运行验收

**没有把这些测试当成实际 Android WebView/手机 UI 验收。** 正常安全设置下的云端 Chromium 运行受 `socket() failed: Operation not permitted` 限制；没有使用关闭沙箱的办法。当前工具链未提供可用 emulator 程序，KVM 不可用；新签名授权未完成，当前 APK 仅未签名编译产物，不能安装。未测触屏布局、SAF 保存重开、真实 IndexedDB 持久化、系统杀进程、低内存或设备速度。旧已交付 APK 不变。
