## 现代模型没有假装接入手机

同项目桌面评估中的 BiRefNet HR-matting 使用 444,473,596 字节权重、Swin/变形卷积等算子。云端 CPU 2048 float32 运行曾被 SIGKILL，无 OOM 日志；显式混合 bfloat16 成功时约 110 秒、峰值约 7 GiB。该结果不代表 Android 或 RTX 4060 性能。

模型包不适合直接塞进此前 18 MB 的 ARM64 APK。当前没有经过验证的该模型 Android/TFLite/NNAPI 导出、量化精度、内存和发热测试。SegFace 的桌面 CPU 推理同样不等于手机接入。

手机仍是 MediaPipe FaceLandmarker + SelfieSegmenter 的原生推理桥。后者是低分辨率人像分割，不是高质量发丝 matting。没有在按钮后面悄悄改成联网服务或冒充本地 AI。

可行的下一步必须分别验证：
1. 更轻量的本地 matting / face parsing 模型转换、精度和真实设备性能；任何额外研究代码仍按实际来源审查授权。
2. 用户选择自己的电脑作为高质量后端，或明确指定可选 API。需要显式的数据传输范围/地址和界面标识。当前没有此类连接，也没有添加 INTERNET 权限。
3. 可选纯离线结果交换只能算跨设备工作流，不能标记为手机原生自动推理。
