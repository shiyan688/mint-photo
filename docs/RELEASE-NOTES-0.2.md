# 薄荷修图 0.2.0 · 体验预览

这一版围绕日常修图和人像创作整理产品体验，让导入、编辑、比较、保存更容易理解。仓库公开的是可本地运行的前端和 Android 工程，发布编号 0.2 用于本次源码体验更新。

## 本次更新

- 重做首页与照片工作区；工具分为调色、人像、构图、创作四组，适配手机和桌面。
- 新增自然通透、暖调日常、冷调清爽快速调色，仍可继续微调。
- 滤镜缩略图由实际像素算法生成；人像高级参数、轻妆与保护面板可以展开。
- 修复连续换图占满作品库的问题；支持确认后永久删除回收项和清空回收站。
- 提供原创 AI 示例人像、真实界面截图和宣传文案。

## 可以体验

- 在同一工作区完成调色、构图、手动精修和创意排版。
- 预览参数后应用修改，随时比较原图、撤销/重做或查看编辑步骤。
- 把作品保存在本地，使用 `.mintproject` 备份原图和编辑历史。
- 在电脑浏览器本地预览；Android 工程保留离线人脸关键点与人物分割能力。

这次整理同时保留了原有曲线/HSL、色阶、局部调色、透视、背景修边、逐人调整等能力。详细功能见 [FEATURES.md](FEATURES.md)。

## 使用方式

在源码根目录运行：

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory app/src/main/assets
```

然后打开 [http://127.0.0.1:8080](http://127.0.0.1:8080)。自动人脸识别和人物分割需要 Android 桥；浏览器端可使用日常编辑和手动工具。

## 这一版的边界

- 提供当前源码构建的 ARM64 / ARM32 Debug 测试包，版本 0.2.0-preview；它使用测试签名。已有旧版可能需要先备份工程再卸载安装。
- Android 真机触控、系统文件选择器、持久化和高负载性能仍需专项验收。
- 当前模型提供关键点与初始蒙版，不提供生成式修图或发丝级抠图。
- 历史私人 QA 照片和派生像素不在公开仓库分发；公开 CI 保留核心、状态、合成像素和 JVM 边界测试，并明确列出未运行的照片审计。

本地公开源码回归 1645/1645 通过；JVM 边界 1116 项与静态桥 37 项通过。真实 Canvas 套件本地 279 项通过、3 项缺历史素材跳过；公开快照会另跳过3项不分发的照片用例。

两种架构 APK 编译、签名、16 KiB 对齐和 85 份资源逐字节核验通过；lint 0 错误、3 警告。浏览器实测了示例导入、快速调色、应用、导出生成和草稿恢复；390像素宽布局已目检。尚未在安卓手机安装验收。
