# 细节 / 锐化：传统、可撤销、默认关闭

这是明确的局部对比工具，不是 AI 去噪、超分、失焦修复、生成缺失细节或 SOTA 美颜。

## 如何使用
1. 打开照片后选「细节 / 锐化」。初始强度为0，不改变任何像素，不增加历史步骤。
2. 从低强度开始，放大检查眼睫、衣物和皮肤。半径默认1；它表示本步骤输入短边为1000像素时的每轴标准差，输入大小改变时同比换算，不跟随查看倍率。
3. 阈值默认3，范围0–30。它减少对轻微明暗变化的增强，不消除已有噪声；阈值0更容易增强噪声、毛孔或JPEG压缩痕迹。
4. 「查看本步前」只切换比较，不存进工程。「本步归零」恢复0/1/3；「应用」提交独立步骤。取消、撤销、重做和步骤回放均保留主原文件。

## 坐标、预览与导出
- 锐化在用户提交的原顺序执行。先裁剪/旋转/留白再锐化，与锐化后再裁剪不是被偷偷重排成同一操作。
- 本步骤不改尺寸和alpha。透明像素的隐藏RGB在纯核心中原样保留，不参与邻域；Canvas自身的预乘量化可能已改变隐藏RGB，不能据此承诺整个浏览器管线无损保存它。
- 半径会按原尺寸或工作尺寸重算，但离散采样、量化、3×3防过冲限制会使预览与原尺寸结果有差别。工作预览放大不是原文件100%像素；导出应明确选择来源并检查结果。
- 不加入便携调色配方v3，不改变旧配方/旧工程含义。本步骤可保存在当前照片有序历史与本地作品库内。

## 资源限制
手机包装层最多8,000,000像素、单边4096；锐化累计估算工作量最多512,000,000，应用于各导出来源尺寸预检。不会先解码超预算原图再假装缩小输出可以绕过。中性步骤工作量为0。

共享核心最多16,777,216像素、单边16384，plan仅检查尺寸/配方而不读取像素。手机8MP的最坏核心新增缓冲区约122.2MiB，加输入约152.7MiB，不含Canvas、历史、运行时和编码开销，因此不保证低内存手机一定可用。取消回调为同步协作式轮询，不等于已验证的手机响应速度。

## 已做与未做
- 本轮实际生产编辑器与已安装Native Canvas进行PNG/JPEG编码回读、顺序几何/透明度、原Blob不变、草稿、应用/撤销/重做和失败回滚测试。
- 公开NASA成人肖像的1000/1600短边派生图用于本地信息性测试。正常阈值下效果较微妙；低阈值高半径确实放大噪声，不能称为自动自然。
- 完整边缘/噪声对照、元数据、来源和生成器在单独质量证据包。大图不重复塞入源码包；小型JPEG夹具、测试和报告保留，解压证据到同一源码目录可恢复图件。
- 当前仅未签名源码/编译检查点，不是新的可安装APK，没有做Android WebView、真机触控、低内存或真实存储持久化验收。旧已交付APK未变化。
