# 多行文字与最近段落再编辑

此模块是真实的本地 Canvas 文字渲染，不是 AI、SOTA 模型或图层管理器。当前源码已接入手机编辑器；云端 Canvas 检查不能替代 Android WebView、系统输入法和真机触控验收。

## 使用

1. 打开「文字」，输入多行内容，调整字号、文本框宽度、行距、对齐、系统字体类别、粗体/斜体、旋转、颜色、透明度、描边与阴影。
2. 拖动画面可移动段落；拖动从原位置按相对距离移动，不会跳到手指位置。抬手才记录位置；失焦、取消或照片版本变化会放弃未完成拖动。
3. 点击「应用」形成一个历史步骤。原照片文件保持不变。
4. 如果最近的有效操作就是新文字段落，可以再次进入文字工具并点「编辑最近段落」。改字、改样式或清空后再次应用，会新增一个替换步骤；「撤销」能恢复前一版段落。
5. 如果段落之后已经有裁剪、调色等操作，就不能直接回改这个较早段落。可以撤销后续步骤，或增加新段落。旧版本的文字/贴纸历史仍能重放，但不会自动升级成可回改段落。

不是任意位置的可编辑图层，也不允许跨过后续编辑偷偷覆盖历史。清空最近段落是可撤销移除；没有改动或新空文字不会占用步骤。所有新增或替换共用现有 60 步上限。

## 控制范围

- 最多 500 个 Unicode 码点、12 行手动换行、128 行自动换行。组合字符/Emoji 尽量按字素单元换行，字形是否存在取决于系统字体。
- 字号是图像短边的 1%–50%；文本框宽度是图像宽度的 5%–100%；行距是字号的 1–2.5 倍。
- 旋转 −180°–180°；透明度 0%–100%；描边宽度为字号的 0%–15%。锚点和拖动坐标是当前编辑阶段图像的归一化坐标。
- 支持系统无衬线/衬线/等宽三类，不下载字体；中文、Emoji、字重和斜体的实际外观由 Android 系统字体决定。
- 段落越过画布边界会裁切，旋转后的选择框仅作辅助，不自动扩展照片。文字可以主动增加透明区域中的不透明像素。
- 换行在标准化测量空间内计算，避免同一字体、相同比例的预览/导出因字号缩放发生漂移。不同系统字体，或裁剪量化导致的极小宽高比变化，不保证逐像素/逐行一致。

## 原图和历史安全

工程保存完整配方而不是路径或字体文件。原图 Blob、其他操作和原始历史不变。重放时只把连续合法的最近段落替换折叠成一次绘制，避免旧文字残留、叠画加深或二次透明度混合。

导入会拒绝缺失字段、未知字段、访问器、非法 Unicode、重复 add ID、找不到目标的 replace、跨 ID 替换和跨过其他操作的替换。撤销/重做完整序列也要通过验证。缺少文字核心时失败关闭，不能静默丢字。

预览使用临时 Canvas，修改已有段落时从该段落之前的操作重新生成底图；不会修改或释放已提交画布。渲染失败保留已提交照片，预览和图像导出成功并不代表系统相册写入已成功。

## 测试命令与边界

普通 Node 测试：

    node --test tests/text-overlay.test.cjs tests/text-overlay-operation.test.cjs

已安装原生 Skia Canvas 的额外验证：

    NODE_PATH=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules node --test tests/native-canvas/text-overlay-core-native.test.cjs tests/native-canvas/text-overlay-ui.test.cjs

第二组依赖已安装的 @napi-rs/canvas，不能冒称浏览器或手机测试。字体输出对比使用当前环境已有 Noto CJK 系统字体。测试无网络、无私照上传、无付费服务、无新签名密钥。
