# 明暗 / 白平衡：手机操作与边界

这是一组传统、可重放的调色控制，不是学习型光照模型、RAW处理、去噪或高光重建。不要把跨端输出一致性当作自然人像质量认证。

## 独立一步

1. 打开照片，选“明暗/白平衡”。阴影和高光均为 −100 至100，0不改变图像。正值提亮、负值压暗对应明度区域。
2. 红、绿、蓝增益可输入0.25至4，1为不变。可分别恢复白平衡为1，或把本次所有控制归零。
3. 点“选取中性灰/白区域”后，画面暂时显示本步骤之前的工作图。选择实际应为灰色或白色、均匀、不反光的中间调区域。彩色物体、肤色不能被当作中性参照。
4. 松手后才接受取样。过暗、过亮、透明、颜色混杂或所需增益过大的区域会拒绝，旧调节保留。重复取样仍读同一份步骤前图像，不反复从已校正图中计算。
5. 应用后加入有序历史。可撤销、重做和恢复草稿；裁剪、旋转、绘画等原有步骤不被重排。

取样来自工作预览，不等于原文件逐像素测光。配方只保存最终RGB增益，不保存取样点、照片、路径或个人信息。第二触点、取消、失焦和导入期间会取消未完成的取样。导入损坏的新图失败后，原照片、旧调节与控件仍可继续使用。

## 可复用配方v3

配方顺序明确为：人像颜色 → 基础调色 → 明暗/白平衡 → 色阶 → 曲线/HSL。

在配方内取样时，专门显示“人像颜色+基础调色”后的输入图，暂不显示本配方的明暗、色阶和曲线，避免从最终合成结果反向估计白点。有人像效果但缺少当前图的人脸定位时，会要求先识别或明确选“仅调色”。

旧v1配方加载时，色阶和明暗均为null；旧v2配方保留色阶，明暗为null。它们不会带入当前尚未应用配方的旧明暗，也不会删除此前已经提交的独立历史步骤。导出统一为v3，不携带源图或取样点。

## 原图与导出

原始文件Blob保留。调色在导出时按历史在实际输出处理尺寸重放，不把放大预览当原分辨率。手机完整处理预算仍为800万像素、最长边4096；末尾缩小输出不能绕过此前原图处理预算。透明度保持；Canvas解码/重编码自身会规范化全透明像素隐藏RGB，不能把它说成原文件每个字节保持不变。

明暗在原色比例上做整体增益，不叠加白色面纱；超出可表示色域时统一缩放RGB，因此可能达不到期望亮度。饱和颜色和极端控制仍可能出现压缩色域或色阶问题；不保证所有极值无色带。极端16:1白平衡增益测试曾出现15码值阶跃；100强度不是自然人像默认值。

同时修复一个相邻导入问题：换主图失败后，已存在的贴图仍可继续编辑；先前未完成的贴图导入和拖动不会晚到覆盖当前状态。

## 测试口径
