# 色阶与配方 v2

本轮是可重放的常规 8 位 sRGB 色阶，不是 RAW、HDR 恢复、AI 美颜或 SOTA 修复。没有新的已签名可安装包，尚未做 Android WebView/真机验收。

## 实际功能
- 进入「色阶」，先选整体 RGB，再选红、绿、蓝通道。可调输入黑点/白点、中间调 γ、输出黑点/白点和总强度；滑杆旁可直接输入精确数值。
- 输入点为 0–255 整数，黑点必须小于白点；输出黑点不得大于白点，可等值。γ 为 0.1–10，强度为 0–1。错误数值不会悄悄改成另一值或覆盖当前图像。
- γ 大于 1 提亮中间调，小于 1 压暗。强度 0 保留参数但不改变照片；可重置当前通道或全部回到中性。默认不自动调整。
- 每次预览从未改变的当前照片阶段重算，不把上一次预览继续累加。应用后新增一个有序步骤，可撤销、重做和草稿恢复，原始照片文件保留。
- 裁剪、旋转、手工修图、涂鸦与色阶按实际操作先后重放，不重排旧编辑。照片版本变化、工具切换或迟到的旧滑杆回调不会改变新会话。

## 命名配方升级
- 「我的配方」新增独立色阶子面板及清除色阶。固定处理顺序为：人像颜色 → 共享基调 → 色阶 → 曲线/HSL。
- 导出严格 v2 格式；色阶字段为 null 或完整合法配方。旧 v1 严格三组输入会迁移成 levels:null，不能夹带新字段。加载旧配方会清除当前未应用的新色阶，不保留隐藏参数。
- 旧收藏只在内存读取时规范化，ID、名称和收藏标记保留；不会因为打开面板自动覆盖存储。只有明确保存/更新后写回。旧版应用不保证能读取新版配方。
- 导出只有调节值，没有照片、路径、标识、人脸关键点、蒙版、几何或笔划。需要人像定位的配方仍使用当前照片重新定位；「仅调色」保留色阶而清除人像效果。
- Android 原生 JSON 校验同时接受严格 v1/v2，仍拒绝重复键、未知字段、非有限数字和大于 64 KiB 的文件。不把浏览器下载触发当作设备文件已写入。

## 验证与限制
- 共享 Levels 与 codec v2 文件逐字节复用桌面冻结版本，非第二套近似数学。
- 云端实际生产编辑器路径验证了中性、最大合法控制、alpha、历史、草稿、失败回滚、裁剪/涂鸦组合与原尺寸 PNG。测试使用真实 Native Canvas 像素及受控 DOM/文件桥，不是手机界面截图。
- 自制图像对比见 quality/levels-evidence/comparison-zh.png；最后的全部中性结果与原图精确相同。
- 同一公开 NASA 派生肖像 897×1000、478 个定位点，在人像/基调/色阶/曲线四组都活跃时，手机配方适配器与完整编辑器原尺寸 PNG 解码输出均和桌面逐字节一致。报告见 LEVELS-PRESET-PUBLIC-PARITY.json。公开肖像仅用于非公开信息性 QA，未成为产品素材或训练集；一致性不代表普遍美感或肤质验收。
- 共享核心可处理更大图像，但手机适配边界保持 800 万像素/4096 最长边并在读取像素前检查。预算不等于最低内存手机已验证可用。
- 处理不恢复原图已丢失的高光细节。极端色阶可以主动剪切明暗或改变颜色；不会因范围合法就承诺自然肤色。
- 本轮未改变已披露 SDK 条款、网络权限、签名身份或模型。不包含新的学习型算法。真实触控/布局、系统文件保存后重新打开、WebView 和手机性能仍待验证。

## 本轮计数
881项纯核心/状态断言、156项真实 Native Canvas 回归及256项Java边界检查通过。另有1项四阶段公开肖像跨端一致性检查，涵盖实际手机适配器及完整编辑器原尺寸PNG解码。计数不代表设备操作次数；主验证JSON列出具体套件与限制。

ARM64/ARM32未签名编译通过；lint为0错误、4项既有警告。39项APK资源与当前源码逐字节一致；离线预览28个内联脚本的CSP哈希匹配，未在浏览器中渲染验收。

原生配方读取器与共享 JS 同样拒绝超过128字符的数字 token 和非零下溢为0的数字；没有把损坏数值静默改为0。

独立复核还发现并关闭原生数字解析与 JS 的边界差异；修后12个差分样例无不一致，重跑实际配方与原尺寸 PNG 一致性也通过。上述用例是有界审查，不是手机触控验收。
