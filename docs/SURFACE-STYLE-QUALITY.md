# 首页、AI 设置与保存界面质量报告

日期：2026-10-25。版本：`0.3.3-dev`（versionCode `8`）。本报告对应冻结程序源码 `1058180c00b0e972ee5b5f46d04c4103aef6f6f4`；[GitHub Actions 验证流程通过](https://github.com/shiyan688/mint-photo/actions/runs/40120891206)。

本轮完成三个界面的黑白与黄绿视觉统一，保留已有编辑、上传确认和保存流程。最终 Android 模拟器证据支持这些操作可用，并确认此前缺失的首页主图标已经实际绘制。本轮没有修改修图像素算法，也不代表已经具备醒图的全部功能或效果。

## 改动范围与操作保持

| 界面 | 本轮改变 | 保留的操作与边界 |
| --- | --- | --- |
| 首页 | 白色底面，黑色主操作，黄绿功能卡片；统一图标、间距与文字层级；明确导入、作品库、人像、AI 和拼图入口。 | 继续调用已有导入、作品库及编辑工具。无照片时，AI 入口先导入，成功后再打开设置；取消导入或改选其他入口不会继续执行过期意图。已有照片时打开 AI 不重置作品。 |
| AI 设置 | 深色面板，分为服务设置、编辑选区、上传确认和结果预览；服务设置每次打开默认展开，长传输说明可折叠。 | 接口、模型和密钥仍使用原字段；上传同意、可能收费提醒及错误状态均不放入折叠区域。关闭会取消进行中的请求，并清空密钥和同意状态；返回结果须明确确认后才作为新照片打开。未新增模型或 API 请求，也不持久化密钥。 |
| 保存照片 | 深色面板，分清格式、尺寸和保存结果；JPG/PNG 卡片显示当前选择。 | 保留原生尺寸 `select`、JPG 画质滑杆和保存流程；格式按钮同步 `aria-pressed`。尺寸错误在未折叠的结果区显示并禁止保存，不会因收起说明而隐藏。 |

用户提供的私有参考截图仅用于理解配色、布局和克制的视觉方向；本报告展示的是应用自身界面，不复制或发布参考截图。

## 首页 SVG 缺失的修复与负对照

早一轮原生截图中，首页主图标不可见，但元素存在且 SVG 路径有几何尺寸。仅检查 DOM 或路径尺寸不足以证明屏幕已经画出图标。本轮将首页图标以静态内联 SVG 放入 HTML，内容取自现有 `MintStudio.icon` 图标映射；运行时初始化跳过已经具有 SVG 的容器。

使用同一探针对图标中心 75% 区域计数，RGB 平均值小于 130 的像素至少为 8 才通过：

| 主入口 | 修复前负对照 | 最终截图深色像素数 |
| --- | ---: | ---: |
| 导入照片 | 0 | 87 |
| 我的作品 | 0 | 202 |
| 人像精修 | 0 | 143 |
| 联网 AI | 0 | 188 |
| 拼图 | 0 | 190 |

[修复前负对照](quality/surfaces-android-20261025/home-icon-paint-negative-control.json)能够检出旧问题，[最终正对照](quality/surfaces-android-20261025/home-icon-paint-positive.json)五项通过。该检查证明这五个位置有可见深色图形，不评价图标形状保真，也不覆盖所有图标。**原始缺失的底层根因尚未确定**，不能将其归因于已证实的 Force Dark、初始化异常或特定 WebView 缺陷；静态内联方案的有效性已有本次截图证据。

## 性能与证据边界

视觉资源只新增 `surfaces.css`，复用已有 SVG 图标；没有新增位图、字体、模糊效果或持续动画。首页待执行操作通过事件驱动的 `MutationObserver` 响应状态变化，没有增加定时轮询。保留画布首次创建时的 `willReadFrequently` 配置。本轮未修改编辑算法、AI 请求协议或图片编码流程。这些是实现范围说明，不等于完成了全机型性能评估。

最终模拟器在 512×512 公共示例照片上记录 12 次交替亮度输入，从输入到两个动画帧的中位数为 **68.25 ms**、P95 为 **132.29 ms**、最大值为 **150 ms**。该数据包含模拟器与自动化环境影响，只描述此样本，不能换算成实体机 FPS，也不能代表大图处理、内存峰值、发热或真实 AI 响应速度。详细样本保存在[汇总报告](quality/surfaces-android-20261025/report.json)。

尚未通过本轮证据验证的范围：

- 实体 Android 手机、不同 WebView/系统版本、真实软键盘弹出与遮挡；CSS 短屏或浏览器缩高不能替代真实 IME 测试。
- 真实 AI 服务的生成效果、人物身份保持、收费行为及不同供应商兼容性；本轮使用模拟服务。
- 全部屏幕尺寸、大图长期使用和持续性能；不将单次模拟器结果泛化为日常使用保证。
- 浏览器一次上传桥调用耗时 **486,087 ms** 属于工具链异常，已从应用性能结论中排除；该次使用故意损坏的 JPEG，坏文件恢复也未计为通过。

完整可复核材料位于[本轮 Android 证据目录](quality/surfaces-android-20261025/)，包含原生结果、点击轨迹、请求图片与蒙版、模拟响应、保存 PNG、截图及像素检查结果。
