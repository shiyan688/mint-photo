# 功能说明

薄荷修图的目标是让日常修图和人像调整在同一张照片上顺畅完成。编辑以有序步骤保存，预览确认后再应用，原文件继续保留。

## 日常修图

| 工具 | 可以做什么 |
| --- | --- |
| 滤镜与基本调节 | 选择风格，调整亮度、对比度、饱和度和色温 |
| 明暗/白平衡 | 分别调整阴影、高光与 RGB 增益；从当前步骤前的画面取样 |
| 曲线/HSL 与色阶 | 控制明暗曲线、颜色区域和整体/分通道黑白点 |
| 局部调色 | 径向、渐变、涂选/套索区域内调整；最多 8 个局部层 |
| 细节/锐化 | 调整强度、半径与阈值；它会增强细节，也可能增强噪声 |
| 裁剪与构图 | 比例裁剪、90°旋转、翻转、任意角调平、四角透视校正 |
| 边框/留白 | 四边分别增加留白，设置底色与透明度 |

## 人像与背景

| 功能 | 浏览器本地预览 | Android 工程 |
| --- | --- | --- |
| 手动修复与液化 | 可用 | 可用 |
| 推动、膨胀、收缩、扭转与恢复 | 可用 | 可用 |
| 自动人脸关键点 | 需要 Android 桥，浏览器不提供 | 使用随包模型 |
| 逐人修肤/塑形 | 需要有效的人脸检测结果 | 检测后选择人物再调整，最多返回 5 张脸 |
| 本轮美颜保护笔划 | 需要有效的人脸检测结果 | 选定人物后涂抹/擦除保护区域 |
| 自动人物蒙版 | 需要 Android 桥，浏览器不提供 | 使用随包分割模型 |
| 手动保留/擦除与修边 | 可用 | 可用 |
| 透明、纯色、照片背景 | 配合手动蒙版使用 | 可从自动蒙版继续手动修边 |
| 证件照尺寸与手动构图 | 可用 | 可用，并可使用检测结果辅助定位 |

自动模型提供位置和初始蒙版。当前修肤与塑形是可调参数的本地算法；手动液化是几何变形，锐化也不等于恢复失焦细节。没有接入生成式换脸、生成式补画或发丝级抠图模型。

人物编号只对应当前照片的这次检测；更换照片或重新识别后，请重新选择人物。大幅塑形、多人相邻影响区和大尺寸图片会受到资源与安全边界限制。

## 创意排版

- **文字：** 多行、换行、对齐、旋转、透明度、描边和阴影，可修改最近一段文字。
- **图片叠加：** 导入本地 PNG/JPEG/WebP，调整大小、位置、旋转和透明度。
- **拼图：** 2–4 格，逐格设置填满/完整显示、焦点、间距和背景。
- **涂鸦：** 每笔单独设置样式，支持透明层橡皮和重编最近涂鸦。
- **符号与遮盖：** 添加符号、局部马赛克或不透明色块。马赛克属于视觉效果，敏感信息建议用完全遮盖并检查导出图。

贴图、照片背景和拼图附图保存的是最长边最多 1024 像素的工作副本，不是完整的多图层设计文件。主照片的原文件仍会保留。

## 保存、重开和导出

| 类型 | 内容 | 适合用途 |
| --- | --- | --- |
| JPG / PNG | 重新编码后的最终图片 | 分享、发布、日常保存 |
| 本地作品 | 原图、已应用步骤、重做历史和内嵌素材 | 在同一浏览器或设备继续编辑 |
| `.mintproject` | 可恢复的完整工程文件，未加密 | 手动备份，恢复到本应用 |
| 我的配方 | 可复用的调色/调整参数，不包含照片或脸坐标 | 将自己的风格用于另一张照片 |

导出可选择 JPG 画质、PNG 透明背景，以及不放大的最终长边。原图重放当前限制为 800 万像素和 4096 像素边长；复杂操作可能需要更低预算。工作图最长边为 2560 像素。界面会提示当前照片可用的导出选项。

作品库与回收区合计最多 24 份/192 MiB，每份工程最多 64 MiB。浏览器的数据清理和应用卸载可能清除本地作品；重要内容请另存 `.mintproject`。工程含原内容，不能当成已脱敏图片分享。

## 当前验证范围

功能来源于实际编辑器和 Android 源码，仓库包含像素、状态、边界、恢复与历史重放测试。主机侧测试和浏览器预览不能代替 Android 真机的触控、文件选择器、存储、内存与模型质量验收。0.2 的实际检查结果以本次发布记录为准；旧检查点报告仅说明对应旧版本。
