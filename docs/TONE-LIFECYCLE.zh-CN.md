# 曲线 / HSL 与草稿安全检查点

日期：2026-10-22。源码检查点，尚无新的已签名可安装版本。

## 新增可用控制

「曲线/HSL」提供整体、红、绿、蓝四条五点曲线，以及红、橙、黄、绿、青、蓝、紫、洋红八色带的色相、饱和度和明度。默认完全不改图。总强度为零或关闭本轮时保持原像素；「应用」后进入有序历史，可撤销、重做、保存草稿，并从保留的原文件重新计算导出。

- 默认曲线从暗到亮单调；自由曲线需显式打开，允许有意反转明暗。
- 曲线图展示当前所选通道自身的完整响应，不含其他通道、HSL 和总强度。
- HSL 按原像素色相在相邻色带间平滑加权，不根据人种、肤色或脸型自动选择参数。相邻色带的极端反向设置仍可能压缩色阶，不承诺所有极端组合没有色带。
- RGB 直方图取自实际预览图，透明度加权；最多 65,536 个确定性分层采样点。明确区分全预览统计和抽样统计。它不是原尺寸全量统计，也不是 RAW 动态范围或可恢复高光的测量。
- 这是 8 位 sRGB 常规调色，不是新的学习型美颜、RAW 处理或 SOTA 质量声明。原有“最大美颜组合过软”限制没有因此消失。

## 同批修复

- 失焦、页面隐藏、丢失触点或指针取消不会误提交未完成的涂抹、裁剪或文字移动。
- 离开人像/手动工具时释放该面板持有的缓存；旧操作仍按历史重放。
- 导出解码或编码期间返回不会触发退出对话框。
- 退出前等待当前已提交修订的 IndexedDB 写入完成；页面隐藏立即尝试刷新，不只依赖 350 毫秒防抖。写入失败会提示，仍允许用户继续退出，不无限困住用户。系统强杀进程的持久化不能保证，尚待真实 Android 生命周期验收。
- 修复笔划面积预算改为分辨率无关的保守几何预算；过大的笔划在小预览中就拒绝，不再到原尺寸导出才因像素底数差异失败。
- 调色适配器复用已有 ImageData，避免额外第三份全幅 RGBA 缓冲。仍保留最多 800 万像素、最长边 4096 的原尺寸导出预算，不保证所有低内存手机均安全。
