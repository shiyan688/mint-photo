# 马赛克与不透明遮盖

本功能是传统像素处理与可撤销画笔，不是 AI 或 SOTA 算法。当前为源码和未签名构建检查点，不是手机验收。

## 两种模式

- **马赛克**：以当前步骤图像左上角为固定格网，使用原始供体像素的透明度加权平均颜色；只替换画笔覆盖区域。可改变色块大小，用于装饰或弱化细节。**不能保证敏感信息不可辨认或不可恢复**。
- **纯色遮盖**：覆盖区域内每个输出像素均替换为指定 RGB 和 255 透明度，即 100% 不透明。没有低透明度、柔边或羽化选项；即便输入是透明 PNG，覆盖区域也会变为不透明。

需要隐藏敏感内容时，应使用纯色遮盖并覆盖得足够完整，导出后放大检查最终结果。缩小、JPEG 有损编码或后续编辑可能影响边缘表现，遗漏在覆盖范围之外的内容不会自动识别。不要只凭马赛克外观判断已安全隐藏。

## 操作和保存

1. 点击「马赛克」，选择马赛克或纯色遮盖，在照片上拖动画笔。单击也可画一个圆点。半径按当前图片短边比例计算。
2. 松手才把一笔加入本轮预览。半径只影响下一笔；切换模式、色块大小或颜色会更新本轮所有笔划。可撤销/重做本轮操作或清空后恢复。
3. 点击「应用」才把本轮写成历史步骤。原图、已提交编辑和后续撤销仍保留。双指导航、失焦或指针取消不会把半笔误提交；仍按住画面时拒绝导出。
4. 操作按当前图像坐标保存，再以相同顺序在原尺寸或明确的工作尺寸重放。裁剪、旋转、翻转和留白不会被偷偷重排。每轮最多 64 笔、合计 4096 点。
5. PNG 保留覆盖范围之外的透明度。JPEG 导出仍会合成到白底并遵守原画质设置。导出从处理后的画布重新编码，不复制输入的原图缩略图或原始 EXIF/XMP。

## 隐私与原图保留不是同一件事

本软件故意保留原始文件和可恢复草稿。因此遮盖**不是安全删除源文件**，也不删除设备中的原照片。只分享检查后的导出图片，不要把原图、工程或草稿当作遮盖结果分享。导出设置中也会显示这项提醒。

## 实现和限制

核心使用连续硬胶囊笔划覆盖，按行计算区间，不以软边模糊冒充不透明遮盖。马赛克使用本步骤开始前的图像供体，不读取已修改结果。零笔划精确不变；失败或取消不修改源像素。

单步继承 800 万像素/4096 边长上限，并在分配前规划额外缓冲与计算量。整条顺序历史还限制马赛克/遮盖的累计估计工作量；原图或中间图的限制不会因最后导出小图而被绕过。预算是工程保守边界，不是手机内存/流畅度保证。

本轮验证采用自制模拟编号，没有私人照片或真实证件数据。实际 PNG/JPEG 像素对照已保存为 `quality/redact-evidence/comparison-zh.png`；它不是手机截图。最终运行记录见 `docs/CLOUD-VALIDATION-2026-10-22.json`。
