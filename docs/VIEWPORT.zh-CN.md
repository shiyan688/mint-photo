# 放大和平移预览

此检查点增加真正的预览导航，不把画布放大伪装成超分辨率。

## 使用

- 「缩放」滑杆在适配倍率的 1–8 倍之间调节，可用键盘或辅助功能调整。
- 「适配」回到完整居中显示。倍率 1× 是适应当前可视区域，不代表原图一像素对应屏幕一像素。
- 图片上双指可缩放和平移。「平移：开」时也能单指拖动图片，但不会同时画笔或修改选区。关闭平移后才能继续单指编辑。
- 第二指落下立即取消尚未完成的画笔、修复、选区或推拉笔划。手势中的任何一指抬起后，剩余手指不会接着绘画；全部抬起再开始新一笔。
- 切换工具、缩放滑杆、重置适配、取消触点、失去捕获或切到后台，均不会把半截笔划当成已完成编辑。
- 裁剪、90度旋转、留白等改变当前图像尺寸后自动回到适配。换照片和查看原图也回到适配，避免沿用不匹配的坐标。平移开关不会偷偷替你切回绘画。

## 与修图的关系

导航只改变 CSS 显示框的位置与大小，不重新采样图片、不记录成编辑操作，也不改变草稿、历史、关键点、蒙版或导出分辨率。手动取样、绘画和局部修复仍通过当前画布边界映射到归一化图像坐标，按原始顺序重放。

页面明确显示当前操作预览尺寸。普通预览通常由最长边900像素的栅格生成，经过构图、留白等操作可能改变尺寸。放大不会增加细节，不等于手机原尺寸像素级修图；原尺寸导出仍按既有预算从保留原图重放。

## 异常手势

最多处理8个带坐标的触点。更多触点会停止编辑并记录最多56个额外触点的释放；所有已记录触点松开后，还需要明确点「适配」才能恢复。超过64个同时活动的触点ID时，不会无限存储或悄悄恢复绘画，而是要求结束浏览器前台手势生命周期后重试。正常双指操作不需要此恢复步骤。
