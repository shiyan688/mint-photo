    作品保存与空间说明

    保存原始图片、已应用编辑、重做历史和内嵌贴图，不只是导出的照片。未应用预览不包含在工程中。所有数据仅在这台设备；清除应用数据或浏览器数据会丢失作品。

    作品与回收区合计最多 24 份 / 192 MiB，每份最多 64 MiB；自动草稿另限 64 MiB。副本也计入额度，实际设备剩余空间和数据库开销可能更早限制保存。回收区不会自动清空，本版不提供永久删除。

    工程备份与恢复

    备份包含哪些内容？

    .mintproject 是未加密的完整工程，含原照片、历史、内嵌素材和已有的人脸坐标；遮盖后的原图仍在备份中，不要当作已脱敏照片分享。仅导出已应用编辑，不含未应用预览。备份不等于本机命名保存，也不是桌面版工程或无照片的调色配方。

    总文件最多 64 MiB，原图最多 40 MiB，首版原图限静态 PNG / JPEG / WebP，动画与 HEIC / GIF 暂不支持。通过系统文件选择位置，请选可信本机位置；“仅本地”是提示，第三方文件提供商仍可能同步至云端。校验和用于检查损坏，不是加密或身份认证。恢复前会校验、解码并重放；当前未保存的已应用编辑会先保留为可恢复副本，空间不足则不替换。
